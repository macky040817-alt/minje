# Week 1 WiL

## 배운 내용
- 프론트엔드의 기본적인 구성을 가볍게 배워보았다. HTML은 웹에서 무엇이 있는지를 표현하고, CSS는 그 요소들이 어떻게 보이는지를 나타내며, Javascript는 웹페이지에 변화와 동작을 만들 수 있다는 점을 알게 되었다.
- DOM에 대해서 가볍게 이해하게 되었다. 직접 chrome의 개발자 모드에 들어간 후 DOM을 통해 요소를 '찾아서 바꿀' 수 있다는 점이 신기했다. document.querySelector를 통해 원하는 요소를 찾고, textContent로 직접 내가 원하는대로 내용을 변경할 수 있음을 확인하게 되었다.
- 사용자의 클릭 같은 행동을 Event로 다룬다는 점을 알게되었다. 단순히 코드를 실행한다기보다 사용자의 행동에 반응하여 화면을 바꾸는 것이 JavaScript의 중요한 기능이라는 점을 알게 되었다.

## 직접 해본 것
- 인터넷 검색으로 head, body, button on click, alert에 대한 간단한 기능을 알아보고 코드를 짜보았다. 이를 이용해 탭 내용, 제목, 클릭이 가능한 첫 홈페이지를 만들어보게 되었다.

## 느낀 점
- 직접 코드를 작성하고 돌려보지는 않았지만, 웹의 기초인 HTML, CSS, Javascript의 역할에 대해서 이해하게 되었다. 
- React는 무슨 역할을 해주는지 궁금하고 기본적인 웹의 구조와 동작 방식에 대해서 더 배워보고 싶다는 생각이 들었다.
