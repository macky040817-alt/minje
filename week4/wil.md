# Week 4 WiL

## 배운 내용
- onClick을 이용해 클릭을 인식하고, 함수를 실행하는 방법을 배웠다. (추가로, handleClick은 클릭 시 실행 / handleClick()은 화면 생성 시 실행)
- useState를 통해 컴포넌트의 상태를 관리할 수 있고, 상태가 변경되면 React가 화면에 반영한다는 것을 배웠다. (const ~ = useState(false) 로 작성) 또한, state를 통해 React가 상태를 기억할 수 있게 함을 알게 되었다.
- useEffect를 이용하면 상태에 따라 영상 재생 같은 기능을 바꿀 수 있다는 것을 배웠다.
- Interaction은 행동에 대한 반응이고, Animation은 변화를 움직임으로 표현하는 것임을 알게 되었다. (움직이 없더라도 화면의 대답은 Interaction이다 **)
- UX 관점에서 화려한 효과보다 사용자가 자신의 행동에 대한 결과를 쉽게 이해할 수 있도록 만드는 것이 중요하다는 것을 배웠다.


## 느낀 점
- 3주차에는 컴포넌트와 Props를 이용해 화면을 구성하는 방법을 배웠는데, 이번에는 사용자의 행동에 따라 화면이 바뀌는 원리를 이해하게 됐다.
- 단순히 기능을 구현하는 것뿐만 아니라 사용자가 결과를 명확하게 인식할 수 있도록 반응을 설계하는 것도 중요하다는 것을 느꼈다.
- 항상 사용자의 입장에서도 생각 해봐야겠다고 느꼈다. (어떤 interaction이 사용자 입장에서 좋을지 생각 ex. 좋아요 누를 시 하트가 어떻게 떠야하나?)
