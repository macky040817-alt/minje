# Week 6 WiL

## 배운 내용
- 지난 5주간 배운 Javascript, react, component, props 등의 개념을 돌아보고, 프론트엔드 개발에 다양한 분야가 있음을 알게되었다.
- 프론트엔트 개발은 단순히 화면을 만드는 것뿐만 아니라 사용자 경험, 기능을 구현하는 것, component 설계, 디자인 등 여러 역할이 있다는 것을 알게 되었다.
- AI를 활용해 화면을 만들 때도 단순히 코드를 생성하는 것보다 원하는 기능과 구조를 명확하게 설명하고, 결과물을 직접 검토하는 과정이 중요함을 알게되었다.

## 직접 해본 것
- 지난 스터디에서 react에서 component와 props를 활용해 인스타 게시물 형태의 화면을 구현해본 것이 가장 기억에 남는다. 처음에는 하나의 코드로 화면을 구현했지만, component로 나누고 props를 통해 데이터를 전달하며 비슷한 구조를 재사용한 점이 흥미로웠다.
- useState를 이용해 사용자의 행동에 따라 화면이 달라지는 원리를 배우며 단순히 화면을 꾸미는 것보다 기능을 구현하는 부분이 더 흥미로웠던 것 같다.

## 느낀 점
- 6주 간 프론트엔드를 공부하면서 내가 가장 흥미를 느낀 부분은 기능 구현과 컴포넌트 설계였다. 화면의 디자인을 다듬는 것보다는 클릭을 했을 때 원하는 동작이 실행되거나, 여러 컴포넌트가 데이터를 주고받는 과정이 더 재미있었다.
- 다음에는 React를 활용해 좋아요 버튼이나 게시물 저장 기능을 직접 구현해보고 싶다. 사용자가 버튼을 클릭했을 때 상태가 변경되고, 그 결과가 화면에 제대로 반영되는지 확인해보고 싶다.
- 이번 스터디를 통해 프론트엔드의 기본적인 구조와 동작 원리를 경험할 수 있었고, 앞으로 다른 개발 분야를 공부할 때도 도움이 될 것 같다고 느꼈다.
