# Week 2 WiL

## 배운 내용
- 2주차에서는 React가 UI를 만들기 위한 Javascript Library라는 것을 배우게 되었다. 
- React가 새로운 프로그래밍 언어인 줄 알고 있었는데 Javascript를 활용하여 화면을 만드는 도구임을 알게 되었다.
- Jsx를 사용하여 Javascript 안에서 HTML과 비슷한 형태로 화면의 구조를 표현할 수 있고, { }를 이용하여 Javascript이 값을 화면에 연결하여 사용할 수 있음을 알게 되었다.
- 평소에는 별 생각 없이 바라보던 게시글을 profile, image, action, content처럼 여러 영역으로 나누어서 생각할 수 있음을 알게되어 다른 시각으로 웹을 바라보게 되었다.

## 직접 해본 것
- 게시글의 프로필과 게시글의 이미지, 본문 등을 직접 수정해보았다.
- 1개의 이미지만 들어간다는 점이 아쉬워서 좌우 버튼을 추가해 2개의 이미지를 넣고 넘길 수 있게 수정해보았다.
- 실제 인스타그램처럼 만들어보기 위해 리포스트 버튼을 추가하였다. (리포스트 이미지를 캡처해서 따와서 넣는 것이 아니라 그림을 만드는 코드? 같은 것이 있다는 것을 알게 되어 신기했다.)

## 느낀 점
- 처음에 React 코드를 봤을 때는 복잡해보이고 각각이 무슨 코드인지 하나도 이해가 안 갔는데 직접 값을 수정해보고 화면이 바뀌는 것을 확인해보니 이해하기 쉬웠다.
- 단순히 강의 내용을 보는 것보다 직접 코드를 수정해보면서 chrome창에서 띄워보니 신기했고, 다음 주에 배울 컴포넌트에 대해서 예습해보고자 하는 생각이 들었다.
- 사진 2장을 넣어 좌우창으로 넘기는 코드를 넣고 돌려보니 react가 화면의 상태를 관리하는데 사용됨을 더 와닿게 이해하게 되었다.
