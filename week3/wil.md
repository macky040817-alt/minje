# Week 3 WiL

## 배운 내용
- React에서 화면을 여러 Component로 나누는 법을 배웠다.
- 하나의 화면을 전부 jsx코드로 작성하지 않고, 역할이 다른 부분을 각각 component로 나누면 코드의 구조를 더 쉽게 파악할 수 있게 된다는 것을 알게 되었다. 
- component에 서로 다른 값을 전달할 때 Props를 사용할 수 있다는 것을 알게 되었다.
- 여러 개의 데이터를 Array로 저장하고, Javascript의 기능인 map을 사용하여 같은 형태의 UI를 반복해서 만들 수 있다는 것을 배웠다. 

## 직접 해본 것
- 먼저 프로필 영역을 Profile Component로 따로 나누고, username과 location을 Props를 통해 게시글마다 다른 이름과 위치가 표시되도록 했다.
- 게시글 데이터는 posts라는 Array에 id, username, location, likeCount, caption 값을 넣어서 수정했다. 
- map()을 사용해서 Array 안의 데이터를 하나씩 Post Component에 전달하고, 게시글이 반복해서 화면에 나타나도록 만들었다.
- 각 게시글마다 좋아요 수와 글 내용도 다르게 보이도록 likeCount와 caption을 추가했다.
- map()을 사용할 때 key={post.id}를 작성했는데, React가 반복되는 게시글들을 각각 구분하기 위해 사용하는 값이라는 것도 알게 되었다.
- 직접 코드를 수정해 보면서 같은 JSX를 여러 번 복사하는 것보다 데이터를 Array에 넣고 map으로 반복해서 보여주는 방식이 훨씬 편리하다는 것을 느꼈다.

## 느낀 점
- 2주차에는 React를 사용해서 화면을 직접 수정하는 것에만 집중했다면, 이번주는 화면을 어떤 기준으로 나눌지 생각하는 점에 집중했다. 
- 단순히 component를 많이 만든다고 좋은 것이 아니고, 각각의 역할을 생각해보면서 나누는 것이 중요하다는 것을 느꼈다. 
- array → map → component로 이루어지는 구조를 이해했고, 각각의 데이터가 화면의 UI 1개로 대응된다고 생각하니 이해하기 쉬웠다. 
- react로 더 큰 화면을 만들 때, 처음부터 코드를 바로 짜기보다 먼저 반복되는 부분과 역할이 다른 부분을 찾아보는 습관을 갖춰야겠다는 생각이 들었다.
